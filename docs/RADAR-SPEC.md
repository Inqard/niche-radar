# Niche Radar — спецификация MVP

Дата: 10.10.2026. Основа: разборы [01](../research/01-niche-research-from-2-videos.md), [02](../research/02-audio-extra-monetization.md), [03](../research/03-niche-catalogs-30-50.md).

## Задача

Каждый день автоматически собирать с YouTube свежие длинные видео по нашим направлениям, находить **каналы-индикаторы** (новые каналы с аномальным ростом), считать конкуренцию в каждой поднише и выдавать **рейтинг подниш** с объяснимыми компонентами. Решение «заходим» принимает человек по отчёту.

## Источник данных

Только официальный YouTube Data API v3 (ключ в `.env`, передаётся заголовком `X-Goog-Api-Key`, в URL и логи не попадает).

| Вызов | Квота | Зачем |
|---|---|---|
| `search.list` | отдельный лимит **100 вызовов/сутки** | Свежие видео по запросам направлений |
| `videos.list chart=mostPopular` (US, по категориям) | 1 ед. | Тренды США вне наших запросов |
| `videos.list` (до 50 id) | 1 ед. | Статистика, длительность, категория, `madeForKids`, платная интеграция |
| `channels.list` (до 50 id) | 1 ед. | Подписчики, число видео, **дата создания канала**, плейлист загрузок |
| `playlistItems.list` | 1 ед. | Последние 50 загрузок канала-кандидата |

Учёт квоты ведётся в БД по суткам Тихоокеанского времени (UTC−8, без перехода на летнее время — погрешность в 1 час допустима).

## Конвейер одного запуска

1. **Поиск:** для каждого запроса × длительность (`medium` 4–20 мин, `long` >20 мин) — `search.list`, order=viewCount, publishedAfter = сейчас − `window_days`, regionCode=US, relevanceLanguage=en. Бюджет вызовов — из конфига.
2. **Тренды:** `mostPopular` по категориям США.
3. **Обогащение:** детали всех найденных видео, их каналов. Каналам-кандидатам (подписчиков ≤ `enrich.max_subs`, есть видео ≥ `enrich.min_hit_views`) — последние 50 загрузок с деталями.
4. **Снимок:** просмотры и подписчики пишутся с отметкой времени запуска. Со второго дня становится доступна реальная скорость «просмотров в сутки».
5. **Скоринг и отчёт:** Markdown-отчёт + CSV + JSON для классификации подниш через Claude.

## Расширение: интересы + все подобные ниши (запрос оператора 10.10.2026)

Список запросов не фиксирован: радар **сам находит соседние подниши** и проверяет их в следующих запусках.

- **Реестр запросов** (таблица `queries`): `seed` (наши интересы из конфига) → `candidate` (найден автоматически) → `active` (уже искали) → `dormant` (низкий score N запусков подряд). У каждого найденного запроса записаны направление и происхождение: от какого запроса и по каким видео.
- **Откуда берутся кандидаты:** теги (`snippet.tags`) и n-граммы названий (2–4 слова) у видео-выбросов и видео каналов-индикаторов. Фраза принимается, если её используют **≥ 2 разных канала** в тегах (≥ 3 — если фраза только из названий: n-граммы названий шумнее тегов); иначе это бренд одного автора, а не подниша. Фразы только из стоп-слов и кликбейта (`generic_words`: «never knew», «crazy facts») отбрасываются. Приоритет = log10(просмотры видео с фразой) × число каналов × score родительской подниши.
- **За пределами интересов:** видео из трендов `mostPopular` по категориям США дают кандидатов с направлением `trending:<категория>` — так видны ниши, о которых мы не думали.
- **Квота:** `search.list` тратится только на поиск новых видео. Каждый запрос × длительность — одна «задача»; задачи перезапускаются не чаще раза в `requery_days`. Бюджет запуска делится: доля `explore_share` — на непроверенных кандидатов, остальное — на устаревшие seed/active. Статистика уже найденных видео и каналов обновляется ежедневно дешёвыми `videos.list` / `channels.list` (1 ед. на 50 объектов) — отсюда снимки и скорость.
- **Темы видео:** `topicDetails.topicCategories` (ссылки на Википедию) сохраняются для группировки соседних ниш.

## Похожие каналы и ручной импорт (v2, 11.10.2026)

Поле «Похожие видео» и персональная главная в API недоступны (`relatedToVideoId` удалён 07.08.2023). Скрапинг HTML YouTube нарушает Условия использования (автоматический доступ запрещён, кроме поисковиков) — **не используем**. Вместо этого — три законных источника:

1. **Рекомендованные каналы** — `channelSections.list` (1 ед.): секции типа `multipleChannels`, поле `contentDetails.channels[]`. Авторы рекомендуют каналы своей ниши.
2. **Публичные подписки автора** — `subscriptions.list?channelId=` (1 ед., 50 на страницу); при закрытых подписках — 403 `subscriptionForbidden`, пропускаем.
3. **Ручной импорт ссылок** — `import-links`: ссылки на видео (`watch?v=`, `youtu.be/`, `/shorts/`, id) и каналы (`/channel/UC…`, `@handle` через `channels.list?forHandle=`). Так попадают «похожие» и главная из браузера (их может собрать оператор или Claude во встроенном браузере).

Расширение запускается от каналов-индикаторов и каналов с выбросами (≤ `related.max_seed_channels`, не чаще раза в `requery_days`). Новые каналы ≤ `enrich.max_subs` получают загрузки (последние 50). Связи хранятся в таблице `related` и показываются в отчёте.

## Подниши по смыслу — кластеры (v2)

Подниша перестаёт быть равной поисковому запросу. Все длинные англоязычные видео окна (из поиска, трендов, загрузок, похожих каналов, импорта) группируются по общим темам:

- **Термины видео:** теги (фразы 1–4 слова) + 1–2-граммы названия, без стоп-слов и кликбейта.
- **Вес:** TF-IDF; термины встречающиеся у < 2 видео или > `max_df_share` видео — отбрасываются.
- **Кластеризация «лидером»** (детерминированно): видео по убыванию просмотров; видео присоединяется к ближайшему кластеру при косинусной близости ≥ `join_similarity`, иначе открывает новый. Затем слияние кластеров с близостью центров ≥ `merge_similarity`.
- **Подниша-кластер** = ≥ `min_videos` видео от ≥ `min_channels` каналов. Имя — верхние термины центроида. Считается тем же score, что и запрос, + показано, **из каких запросов** собрались видео (видно слияние/расщепление запросов).
- Верхние термины кластера, ещё не бывшие запросами, становятся кандидатами в поиск (`origin=cluster`).

## Контур Claude (v2, без платного API)

- `claude_input-*.json` — кластеры: термины, примеры названий, запросы-источники, метрики; рядом `claude_prompt.md` с форматом ответа.
- Claude (в сессии Claude Code) отвечает JSON: имена подниш, вердикт/риски, **новые соседние запросы**.
- `import-claude ответ.json` — имена применяются к кластерам с тем же ведущим термином; новые запросы → кандидаты (`origin=claude`, повышенный приоритет).
- Автоматический вызов Claude API — платный сервис, подключается только по решению оператора.

## Метрики

Длинным считается видео ≥ 240 с. Метрики канала считаются только по длинным видео старше 3 суток.

| Метрика | Определение | Откуда правило |
|---|---|---|
| `views_per_day` | По снимкам: Δпросмотров / Δчасов × 24; до второго снимка — просмотры / возраст | [01 §7.1] |
| `views_per_sub` | Просмотры видео / подписчики канала | «аномалия» у В1/В2 |
| `outlier` | Видео за окно с просмотрами ≥ `outlier_min_views` и `views_per_sub` ≥ `outlier_ratio` | В1 (47K подписчиков, 5.7M просмотров) |
| `seriality` | Доля длинных видео канала с просмотрами ≥ 25% лучшего видео | В4 «серийные просмотры» |
| `top2_share` | Доля двух лучших видео в сумме просмотров; флаг `one_hit`, если > 0.7 при ≥ 5 видео | В4 «ниша-однодневка» |
| `growth_ratio` | Медиана последних k видео / медиана первых k (k = min(5, n/2)) | В2 «аномальный рост» |
| `possible_demonetized` | Регулярный канал (медианный интервал ≤ 7 дн., ≥ 5 видео) молчит ≥ max(14, 3× интервал) дней | В1 23:19 |
| `template_score` | Доля самого частого «скелета» названия (первые 3 слова, цифры → #) | inauthentic content, [01 §6] |
| `numbered_share` | Доля названий с `#N` / `Part N` / `Episode N` | В5 (BeamNG #56) |
| `paid_share`, `monetization_signals` | Флаг платной интеграции; ссылки на Patreon/Gumroad/партнёрки в описании | [02 §4] |
| `kids_share` | Доля видео с `madeForKids` | COPPA, RPM Kids $0.33 |
| `risk_flags` | Ключевые слова: медицина, политика, детское, 18+-байт, «спасения» животных, чужие франшизы | [03 §4] |
| `rpm_prior` | Медиана AIR 2026 по категории видео | [03 §2] |
| `views_per_day`, `subs_per_day` (канал) | Δ просмотров и подписчиков канала по снимкам `channel_stats`: последний снимок против ближайшего к 7 дням назад, интервал ≥ 0.8 сут. | В1 27:19 (vidIQ «за 7 дней») |
| `evergreen_share` (подниша) | Σ max(0, просм./сутки канала − просм./сутки его видео моложе 30 дн.) ÷ Σ просм./сутки каналов. Считается только по каналам с известными загрузками | В1 17:11, В4 1:05:03, В5 5:39 (вечнозелёное против хайпа) |
| `median_minutes` (подниша) | Медиана длительности видео подниши | В1 49:28, В4 7:04, В5 2:35 |
| `content_farm` (канал) | ≥ 5 длинных видео, медианный интервал ≤ 0.5 сут. | В1 54:52 |
| `ai_label` (флаг видео) | Автор сам отметил реалистичный изменённый или сгенерированный контент (`status.containsSyntheticMedia`) | В4 19:41, В5 11:14 |

**Ритм выпуска** (`median_interval`, `days_since_last`, `possible_demonetized`, `content_farm`) считается **только у каналов с известными загрузками**. Без полного списка загрузок большой канал по нескольким найденным роликам выглядит «замолчавшим»: в живых данных 11.10 так было с 9 из 36 флагов.

**Канал-индикатор** (все условия, пороги в конфиге): возраст ≤ 120 дн. (В2: ≤ 60, расширено), видео 3–60 (В2: 10–50), подписчиков < 100K (В1), лучшее видео ≥ 100K **или** `growth_ratio` ≥ 5, нет флага `one_hit`.

**Закрепившийся конкурент в поднише:** канал с видео в окне ≥ `min_hit_views` и (подписчиков ≥ 100K или возраст ≥ 365 дн.).

## Широкая карта ниш (оператор, 11.10.2026: «абсолютно все ниши и подниши»)

Семена поиска — не только интересы: `[explore_directions]` в `radar.toml` — 20 областей YouTube, 181 запрос (форматы, история, наука, деньги, криминал, люди, психология, дом, путешествия, транспорт, военное, кино, спорт, техника, музыка, природа, игры, паранормальное, детское, общество). Ищутся раз в `explore_requery_days` (10), только 4–20 мин; планировщик меряет «просроченность» в циклах, чтобы карта и интересы конкурировали честно. Тренды — 12 категорий × 4 региона (US, GB, CA, AU). Граф похожих каналов расширен (80 семян, 150 новых каналов за запуск). Единственный предел широты — 100 search.list/сутки: полный круг карты 10 дней; заявка на расширение квоты — шаг оператора (README).

**Метрики «хайпа сейчас» из гайдов:** `fresh_views` (видео ≤ 14 дн — В1 «сок»), `momentum` = (свежие/14) ÷ max(старые/16, floor) — разгоняется ли тема; `top_video_share` > 0.7 — прострел одного ролика, а не ниша (В4) — такие группы в отдельном разделе отчёта, не скрыты; `demonetized_channels` — каналы ниши, которые замолчали (В1).

## Правило отбора (оператор, 11.10.2026)

**Порядок = просмотры.** Доход приходит за просмотры; высокий RPM не обязателен — меньше за 1000, но больше просмотров тоже годится. Отчёт даёт три ранжирования подниш по смыслу: по просмотрам за окно, по скорости (просм./сутки), по «окну возможностей» (формула ниже). RPM-ориентир по категории, деньги вне рекламы (интеграции, Patreon), риски и доля «для детей» — **справочные колонки рядом с каждой строкой, в рейтинг не входят**. Вердиктов go/skip радар и разметка не ставят: отбираем топ, решение о входе — за оператором.

## Окно возможностей (score; справочно)

```
demand        = log10(1 + сумма просмотров длинных англоязычных видео подниши за окно)
newcomers     = 1 + 0.5 × min(каналов-индикаторов, 5)
crowding      = 1 / (1 + max(0, закрепившихся − 6))           # В1: > 5–6 = переполнено
seriality     = 0.5 + медиана seriality каналов подниши        # 0.5…1.5
score         = demand × newcomers × crowding × seriality
```
Было до 11.10: × money (sqrt RPM-ориентира) × risk (1 − 0.8 × доля рисковых) — убрано: категорию ставит сам автор (ESL и «female psychology» были Education), а риски и RPM — информация для оператора, не множитель.

**Веса и пороги — стартовые гипотезы, не истина.** Отчёт показывает все компоненты, чтобы ранжирование можно было оспорить. Калибруем после 1–2 недель снимков.

## Ограничения (известные, принятые)

- «Похожие видео» и главная напрямую недоступны — заменены рекомендованными каналами, публичными подписками и ручным импортом (v2).
- Кластеры — лексические (общие термины), не смысловые: синонимы без общих слов могут не слиться — это доделывает контур Claude.
- `rpm_prior` — медиана глобальной выборки AIR, а не доход канала. Оценки выручки в отчёте не показываются.
- Публичные просмотры с 27.08.2026 считаются с первого кадра; сравниваем видео только внутри одного окна.

## Критерии готовности MVP

1. Юнит-тесты метрик проходят.
2. Офлайн-прогон всего конвейера на поддельном API: создаётся отчёт; канал-индикатор найден; канал-«однодневка» помечен; переполненная подниша ниже свободной; счётчики квоты совпадают с числом вызовов; ключ API не попадает ни в один выходной файл.
3. v2 офлайн: канал, известный только из рекомендаций/подписок индикатора, попадает в базу с загрузками и в отчёт; закрытые подписки не ломают запуск; видео двух запросов с общими терминами сливаются в один кластер, несвязанные — нет; кластеризация не зависит от хеш-соли; импорт распознаёт все форматы ссылок; `import-claude` даёт имена кластерам и новых кандидатов.
4. Боевой прогон (после появления ключа): расход `search.list` ≤ бюджета из конфига, отчёт с ≥ 1 подниши по каждому направлению.
