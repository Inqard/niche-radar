# Методика из видео → Niche Radar: матрица покрытия

Сверка 11.10.2026 по **полным расшифровкам** (а не только по конспектам). Источники:
- В1 — 2-часовой гайд;
- В2 — фундаментальный курс;
- аудио — дополнительная монетизация;
- В4 — «30 ниш»;
- В5 — «50 ниш, ч. 1».

Расшифровки лежат в приватной папке `research/transcripts/`. Здесь учтены только приёмы **поиска и оценки ниш**. Производство (озвучка, монтаж, превью), регистрация канала и способы вывода денег — следующий этап, не задача радара.

Обозначения:
- ✅ — было реализовано;
- 🆕 — добавлено по этой сверке;
- 🟡 — частично или замена, потому что API не даёт;
- ⛔ — недоступно или не делаем; причина указана.

## Как проверить

- **Тесты:** `python -m pytest -q` — 91 проходит. Новые проверки — в конце `tests/test_pipeline_offline.py` (блок `VIDEO-COVERAGE`), в `tests/test_metrics.py` и `tests/test_clusters.py`. Каждая падает, если убрать то, что она проверяет: мутационные пробы 7 из 7 и 5 из 5, 11.10.2026.
- **Отчёт:** `python -m niche_radar report` перестраивает отчёт без вызовов API.
  - Колонки «Мин.» и «Вечнозел.», раздел §3a (карточки) и §10a (топ месяца по категориям) появляются сразу.
  - §10a заполнится после первого боевого прогона.
  - Скорость каналов и «Вечнозел.» — после второго дня снимков: нужны два снимка канала с разницей ≥ 0.8 суток.
- **Квота:** первый прогон после правки один раз потратит ~30 из 80 поисков на 15 категорий × 2 длительности. Дальше категории повторяются раз в 14 дней, около 2 поисков в сутки. Инвариант квоты — `tests/test_config.py`.
