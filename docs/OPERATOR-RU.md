# Niche Radar — памятка оператора (RU)

Публичный README — на английском (`README.md`). Здесь — рабочие заметки.

- `research/` — разборы обучающих видео и проверка фактов (01–04), расшифровки в `research/transcripts/`.
  В публичный репозиторий не входит (личный контекст).
- `docs/RADAR-SPEC.md` — спецификация: метрики, пороги, формула, аудит фильтров, правила отбора.
- `docs/QUOTA-REQUEST.md` — пакет для заявки на квоту (не в публичном репозитории).
- `radar.toml` — настройки: направления интересов, широкая карта ниш, пороги, риски, хранение.

## Команды (из папки проекта)

```bash
python -u -m niche_radar run          # поиск + обновление + скоринг + автопоиск подниш + отчёт
python -m niche_radar report          # пересчитать отчёт из базы без вызовов API
python -m niche_radar quota           # расход квоты за сутки
python -m niche_radar add-query "ancient engineering" --direction tech_explainers
python -m niche_radar import-links --direction languages https://youtu.be/… https://www.youtube.com/@handle
python -m niche_radar import-claude data/reports/claude_answer.json
python -m pytest -q
```

Результаты: `data/reports/radar-ГГГГ-ММ-ДД.md`, `niches-*.csv`, `clusters-*.csv`, `channels-*.csv`,
`claude_input-*.json` + `claude_prompt.md`. База: `data/radar.sqlite`. Логи автозапуска: `data/logs/`.

## Как читать отчёт

- **Порядок = просмотры.** RPM-ориентир, деньги вне рекламы, риски — справочные колонки, в рейтинг не входят.
- Три ранжирования подниш по смыслу: по просмотрам за 30 дней, по импульсу (14 дней против предыдущих), по «окну возможностей».
  Одиночные прострелы (один ролик > 70% просмотров группы) — отдельный раздел.
- Реальная скорость «просмотров в сутки» появляется со второго ежедневного запуска.

## Автозапуск

Задача планировщика Windows «NicheRadar Daily», 12:30 по Еревану (после сброса квоты Google), скрипт `scripts/run_daily.ps1`.

## Квота

`search.list` — 100 вызовов в сутки; радар тратит до 80: ~40% на автонайденные подниши, остальное — семена
(интересы раз в 4 дня, карта раз в 10 дней). Расширение квоты — заявка Google (`docs/QUOTA-REQUEST.md`).

## Похожие видео, главная, подниши по смыслу

- Похожие каналы находятся через рекомендации на страницах каналов и публичные подписки.
- «Похожие видео» и главная в API недоступны — ссылки добавляются через `import-links`.
- Подниши по смыслу — лексические кластеры (теги + фразы названий, TF-IDF).
- Контур Claude: `claude_input-*.json` + `claude_prompt.md` → ответ JSON → `import-claude` (имена и факты, без вердиктов).
