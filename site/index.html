Niche Radar

A free, open-source research tool for independent creators: it monitors publicly available YouTube statistics and shows which long-form topics audiences are watching, how crowded each topic is, and which new channels are growing — so a creator can plan videos from evidence.

Source code and documentation: github.com/Inqard/niche-radar (MIT license). Each creator runs the tool on their own computer with their own Google Cloud project and API key.

This application uses YouTube API Services. All video and channel data in its reports is sourced from YouTube.

What it does

  • Reads public data only: video titles, descriptions, tags, publication dates, durations and public statistics (views, likes, comments); public channel metadata and statistics; public channel sections and subscriptions; "most popular" charts.
  • Groups recent long-form videos into topics and ranks topics by audience interest, so the creator can decide what to make next.
  • Flags patterns a creator should know about before choosing a topic — templated or numbered series, content labelled "made for kids", channels that suddenly stopped uploading — to help creators avoid producing mass-produced or unsuitable content.
  • Runs once a day on the creator's own computer as a command-line tool. There are no accounts, no sign-in and no hosted service.

What it does not do

  • It does not access any private or user-authorized data and does not use OAuth.
  • It does not download, cache or store any video or audio content.
  • It does not scrape YouTube; all data is retrieved exclusively through the official YouTube Data API.
  • It does not publish, sell or share the retrieved data; reports stay on the creator's computer.
  • Public statistics are kept for at most 30 days and are then refreshed or deleted.
